## 2. Atomicidade — provada por árvore, não por leitura do commit

O pedido é: *não existe árvore intermediária em que o arquivo mudou de nome e uma citação viva ainda
aponta para o antigo.* Isso **não** se prova dizendo "está tudo num commit"; prova-se avaliando o
invariante em **cada** árvore alcançável na branch.

```
$ for c in c7df90c 73b8392 592eb25; do for tok in test_durabilidade_da_infra test_etl_backlog_retomavel; do
    git cat-file -e $c:backend/tests/sentimento/$tok.py && echo EXISTE || echo AUSENTE
    git grep -c -F "$tok" $c -- backend/README.md backend/src backend/tests   # citações VIVAS
  done; done
```

| árvore | token | arquivo antigo | citações VIVAS ao token antigo |
|---|---|---|---|
| `c7df90c` (base) | `test_durabilidade_da_infra` | **EXISTE** | **4** |
| `c7df90c` (base) | `test_etl_backlog_retomavel` | **EXISTE** | **3** |
| `73b8392` (rename) | ambos | **AUSENTE** | **0** |
| `592eb25` (relatório) | ambos | **AUSENTE** | **0** |

**O invariante `(arquivo EXISTE ∧ citações > 0) ∨ (arquivo AUSENTE ∧ citações = 0)` vale nas 3 árvores.**
A transição acontece em **exatamente um** commit. Confirmado pelo `name-status` de `73b8392`, que carrega
os 2 `R` **e** as 2 citações de produção no mesmo objeto:
