## Como reproduzir o `200` com `0` valores, sem subir nada de produção

A API de produção serve o catálogo **antigo** (11 linhas) e responde `422` para este
`series_key_id`. Para ver a resposta real, suba uma API efêmera na rede do compose com este branch
montado:

```bash
docker run -d --rm --name ls-api-probe --network deploy_default \
  --env-file /home/stharley/Documentos/projects/cripto-strategy/.env \
  -e APP_PORT=8000 -e APP_HOST=0.0.0.0 \
  -v deploy_api_data:/app/data/md \
  -v <ESTA-WORKTREE>/backend/src:/app/src:ro \
  -p 18099:8000 -w /app deploy-api python -m src.main
# depois: GET http://localhost:18099/api/v1/series-history?series_key_id=279d3172…&symbol=BTCUSDT
#         &interval=1m&window_start_ms=…&window_end_ms=…&knowledge_time_ms=…&bar_policy=final_only
docker rm -f ls-api-probe   # ⛔ SEMPRE, ao terminar
```

⚠️ `-v deploy_api_data:/app/data/md` é obrigatório: sem ele o boot morre em
`store_parent_missing: data/md`.

⚠️ E ver [`PENDENCIAS-PARA-AVALIAR-DEPOIS.md`](../PENDENCIAS-PARA-AVALIAR-DEPOIS.md) §F antes de
