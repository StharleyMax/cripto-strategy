## 2. A decisão que a task existe para proteger — `1.4b`

`KlineRow` guarda o array **verbatim** em `raw: tuple[KlineField, ...]` e **recusa existir** com
qualquer aridade que não 12 (`KlineArityError` no `__post_init__`). Os acessores nomeados
(`volume` → `[5]`, `taker_buy_base_volume` → `[9]`, `open_time_ms`, `close_time_ms`) são
conveniência **sobre** `raw`, nunca substituto dele. Os índices não são literais soltos: saem de
`KLINE_FIELD_NAMES.index(...)` sobre a tupla dos 12 nomes, que é a forma escrita do contrato.

Isso é o que faz a fase `02` (CVD) custar zero integração nova:
`delta_cvd = 2 * takerBuyBaseVol - volume`, da **mesma** resposta
(`ACHADO-KLINES-CVD.md`, `ADR-036/D5`).
