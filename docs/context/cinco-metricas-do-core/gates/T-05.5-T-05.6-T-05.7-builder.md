## Falsificadores que eu deixo em aberto, nomeados

1. **`weight_used = n_calls`.** Argumento: o teto deste balde é denominado **em chamadas**
   (40/60 s medidas), então o preço de uma chamada é 1 unidade **por definição da unidade**, e
   a contagem é nossa porque o balde é BLIND. **Se alguém provar que a Coinalyze pesa endpoints
   diferentemente, este número vira derivação sem medição** e o campo tem de voltar para
   `WEIGHT_NOT_READABLE`.
2. **`DEFAULT_LOOKBACK_SECONDS = 3 h`.** Escolhido porque a largura da janela é grátis
   `[DOC: MEDICAO §4.2.3-§4.2.5]`. **Não medi** o custo de parsear 180 buckets × N símbolos por
   ciclo; se a CPU do coletor subir, é aqui.
3. **`_LIQUIDATION_RECOIL` (30 s / ×2 / teto 300 s).** É só o FALLBACK para `429` **sem**
   header. Os três `Retry-After` observados (49,1 / 56,8 / 59,0 s) vencem a base em todos os
   casos, então **a base nunca foi exercitada contra a origem real** — `[NÃO MEDIDO]`.
4. **`UNANSWERED_SYMBOL` com `n_missing = 0`.** O número de buckets que faltam é
   desconhecido numa série esparsa (era `0` legítimo?), e inventá-lo seria pior que deixá-lo
   em zero. **A lacuna é registrada pelo `gap_class`, não pela contagem.**
