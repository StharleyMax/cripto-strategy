O coletor lê variáveis por `env_file: ../.env` (`deploy/compose.yml`). A variável vale **só para o
primeiro ciclo** após o boot.

```bash

echo 'LIQUIDATION_FIRST_CYCLE_LOOKBACK_S=432000' >> .env
docker compose -f deploy/compose.yml up -d --build collector      # mesmo comando já usado na feature
# T_deploy = started_at do 1º run de liquidação pós-deploy:

    where endpoint = '/v1/liquidation-history' order by started_at desc limit 3;"
# se o 1º run vier com 'unanswered symbols: …BTCUSDT…' em notes, repetir o `up -d --force-recreate collector`
# 1) voltar ao default: remover a linha do .env e recriar

docker compose -f deploy/compose.yml up -d --force-recreate collector
```
