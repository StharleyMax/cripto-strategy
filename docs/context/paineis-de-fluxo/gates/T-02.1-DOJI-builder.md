## O que mudou

**Código** — `volumeBarColor` (`volume-direction.ts`):

```ts
if (candle.close === candle.open) {
  return dojiItemColors().color;
}
return candle.close > candle.open ? tokens.directionUpFill : tokens.directionDownFill;
```

- O ramo do doji lê `dojiItemColors().color`, não `tokens.provenanceWeak` pelo nome. É a exigência do
  julgamento §3: a barra não consegue divergir da vela doji mesmo que o token da vela mude.
- O predicado é o mesmo de `candlestickSeriesLossless` (`s2-lightweight-adapter.ts`, `open === close`).
- A doc do topo perdeu o parágrafo *"The two disagree on purpose"* e cita `ADR-010/D-2` (`:110`), `ADR-010:66`
  e o julgamento. O `[INFERRED: I-3]` fica registrado como **revogado**, com o motivo.

**Teste** — `volume-direction.test.ts`:
- DoD caso 3: espera `dojiItemColors().color`, pinado em `#8b949e`, e `notEqual` a `UP` e a `DOWN`. A tag
  `[INFERRED: I-3]` saiu.
- Pareamento por tempo: a barra de `T0+2·MIN` (vela `10→10`) passou de `UP` para `dojiItemColors().color`.
- O cabeçalho do arquivo diz o novo MORDE ("2 dos 4" + "o 3º pelo colapso do doji").
