contrato: **acessor ÚNICO** `as_of()` = `argmin(observed_at)`, com **LOCF**, **sem interpolate**,

**"Acessor ÚNICO" é a metade que se perde primeiro.** Se existirem dois caminhos de leitura da série,
um deles vai divergir em silêncio. O falsificador natural: procure por qualquer outro lugar que leia a
série sem passar por aqui, e prove que não existe — não que você não achou.

**`sem interpolate` é regra anti-lookahead.** Este repositório já teve **uma regra anti-lookahead
invertida e propagada por dois documentos**, achada pela disciplina de citar o comando. Interpolar
entre dois pontos usa o ponto **futuro** para produzir o valor presente. LOCF (*last observation
carried forward*) só olha para trás. **Se você se pegar escrevendo algo que precisa do próximo ponto,
pare** — é a falha que a task existe para impedir.
