## 1. O `availability_probe_set` declarado (`Q19`)

`docs/decisoes-do-owner.md` §Q19, `[PREMISSA-OWNER: 2026-09-02]` literal — símbolos
`BTCUSDT`/`ETHUSDT`/`LINKUSDT`/`SOLUSDT`; `[DECISÃO-OWNER: 2026-09-02]` — 10s nos 5 endpoints
`/futures/data/*`, Coinalyze incluída na mesma rodada. `domain/availability_probe_set.py`
declara os dois lados e VALIDA `D3.3` na própria construção (`__post_init__` refuses):

- Binance: 5 endpoints x 4 símbolos = 20 chamadas/sweep; a 10s, `20 x 6 = 120` chamadas/min
  (60% de 200/min) — bate exatamente o número do owner.
- Coinalyze: 2 endpoints x 4 símbolos = 8 chamadas/sweep; a 30s (não copiado do número da
  Binance — `12s` já bastaria para caber), `8 x 2 = 16` chamadas/min (40% de 40/min, balde
  CEGO — margem deliberada porque a resposta `200` não confirma quanto falta).
- `período >= 60s` REPROVA sozinho, independente de orçamento (mais grosso que a dispersão
  99,6–200,8s já medida) — testado em
  `test_availability_probe_set.py::test_a_period_of_sixty_seconds_is_refused_regardless_of_budget`.

Os 5 endpoints Binance são os mesmos que `domain/metrics_shift.py` já nomeia do lado do dump
`daily/metrics` (`openInterestHist`, `topLongShortAccountRatio`, `topLongShortPositionRatio`,
`globalLongShortAccountRatio`, `takerlongshortRatio`) — mesmo conjunto, não um novo. Os 2
endpoints Coinalyze reusam os paths já declarados por `CA-F0-13`
(`domain/coinalyze_daily_series.ENDPOINT_PATH_BY_KIND`), pedidos a `interval=1min` (não
`daily`) para que uma transição seja observável numa rodada de minutos.

## 3. O falsificador — os casos que a proteção REJEITA

```bash
cd backend && .venv/bin/python -c "
from src.modules.sentimento.domain.availability_probe_set import AvailabilityProbeSet
try:
    AvailabilityProbeSet(symbols=('BTCUSDT',), binance_period_seconds=60.0, coinalyze_period_seconds=30.0)
    print('FALHOU: deveria ter reprovado')

```
→ `REJEITOU corretamente: binance_period_seconds=60.0 >= 60.0: D3.3 reprova — mais grosso que a
dispersao medida (99,6-200,8 s), custa cota e nao informa` (`rc=0`, saída acima).

(20 símbolos a 10s = 600/min, reprova), `test_a_period_that_blows_the_coinalyze_blind_budget_is_refused`
(96/min contra balde cego de 40), `test_a_sample_cannot_claim_knowledge_before_the_fact_happened`
(`AvailabilityLagSample` recusa `available_at < event_time`).
