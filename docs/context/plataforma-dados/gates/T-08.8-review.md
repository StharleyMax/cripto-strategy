## O ponto de julgamento: ausência dos números literais de D8.2

DoD `D8.2` (`docs/plans/SPEC-001-plataforma-dados/08_superficie_e_reprodutibilidade.md:27`) descreve o
produto fim-a-fim: **"a célula lê tautológico — janelas idênticas, nunca 1,04%"** (isto É verificado:
`InSampleFiringRate.rate` é `None` por tipo, herdado de `T-08.6`) e os números OOS (média 1,404%, máx
12,847%, 52× em q=99,9) — que descrevem a LEITURA NA UI sobre DADO REAL, não a mecânica interna.
`tasks.toml` só lista `T-08.8` como dona de `D8.2` — não há outra task nomeada para fechar o resto.
`ADR-023` nomeia explicitamente a legenda de UI como fora de escopo (gate `ux-ui-mastery`, task distinta)
e dado real como dependência de `T-01.8`/infra (ainda não construída). A alegação de `ADR-023` de que
uma fixture "BTC/30d" seria reaproveitável (`ADR-023:43-46`) é falsa por inspeção — confirmei eu mesmo:
`backend/tests/helpers/charts_fixtures.py:66-79` (`synthetic_btc_like_population`) é uma população de
101 escalares sem eixo de tempo, incapaz de produzir 23 folds diários.

**Julgamento:** isto é gap real de `ADR-023` (premissa de fixture errada), não de `T-08.8`. Fechar o
número literal aqui exigiria fabricar uma série sintética construída para bater com uma resposta
pré-determinada — o próprio anti-padrão que este repositório recusa ("Nenhum número sem o comando", e o
precedente de `T-08.1`/QA que reprovou exatamente esse tipo de atalho). O falsificador ESTRUTURAL
(`n=23` a partir de `30/7/1`) e o de comportamento (anti-lookahead/anti-tautologia) — os dois que `ADR-023`
chama reproduzíveis "sem precisar de dado real" — estão provados por teste. **Não bloqueia esta task**;
fica nomeado para o `quant-architect`/owner emendar `ADR-023` (a lacuna já está registrada no gate de QA,
não escondida).
