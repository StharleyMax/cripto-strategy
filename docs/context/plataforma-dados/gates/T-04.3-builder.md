## 2. Desenho

`plano 04` item 4.3, literal: "Unicidade por `agg_id` com verificação de contiguidade — nunca
por tempo, nunca `first`/`last trade_id`". `AggTradeTick` carrega só `agg_id` e
`transact_time_ms` — não existe campo para `trade_id`, o que torna "nunca por trade_id" uma
garantia estrutural (o mesmo padrão de `stream_probe_outcome.ProbeNotMeasured`), não uma
convenção que um chamador precisa lembrar.

`AggIdGap.n_missing = to_agg_id - from_agg_id` (a LARGURA do buraco em espaço de id), e não
`to - from - 1` (a contagem de inteiros estritamente entre os dois) — decisão tomada porque é
esse o número que `D4.4` cita literalmente (`1.620.908`, não `1.620.907`). A convenção está
pinada num teste sintético pequeno antes de aparecer no fixture real, e um mutante que troca
para `delta - 1` derruba os dois testes que citam o número (ver §5).
