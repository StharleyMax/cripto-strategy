## Falsificador mostrado (o que a proteção rejeita)

`test_resolve_returns_the_old_symbol_strictly_before_effective_from`: com um alias
`MATICUSDT -> POLUSDT` (`effective_from = 2024-09-05`), `resolve("MATICUSDT", at=2024-09-04)`
(um dia ANTES) tem que devolver `"MATICUSDT"` inalterado — pegaria uma inversão `<`/`<=`.
`test_resolve_refuses_a_cycle`: uma curadoria `A -> B`, `B -> A` levanta `AliasCycleError` em
vez de laçar para sempre — prova que o bound de `len(entries)` hops + `visited` funciona.
`test_from_raw_refuses_an_unexpected_field`/`test_from_raw_refuses_a_missing_field`: uma
entrada com 5ª chave ou faltando uma das 4 é recusada por nome, nunca aceita com o typo
silenciosamente ignorado.
