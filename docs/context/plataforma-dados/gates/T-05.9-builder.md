## 4. Como o módulo fecha `DoD D5.8`

1. **Chave endereçável por conteúdo** — os seis termos de `ADR-005/D1`, URL canônica, mesmo
   padrão de `encodeBundle`/`decodeBundle` (`T-05.8`).
2. **"O cache É o `knowledge_time`" (`D1`)** — `contentAddress` discrimina por qualquer termo
   da chave (testado: só `knowledgeTime` muda ⇒ endereço muda; só `barPolicy` muda ⇒ endereço
   muda). `HistoryResponseCache.set` RECUSA (lança) se a MESMA chave receber um payload
   diferente — a imutabilidade da ADR como invariante verificável, não comentário.
3. **`bar_policy` nunca default (`D4`)** — `decodeHistoryRequest` recusa parâmetro ausente ou
   fora de `{final_only, intrabar}`; nenhuma função tem default para o campo.
4. **Zero campo de nível de tick** — `assertNoTickLevelFields` percorre qualquer JSON
   decodificado em qualquer profundidade, recusando `agg_id`, `agg_trade_id`, `price`,
   `quantity`, `first_trade_id`, `last_trade_id`, `transact_time`, `is_buyer_maker` — conjunto
   transcrito do falsificador da ADR **e** do cabeçalho real do dump (`head -2
   data/binance/aggtrades/BTCUSDT-aggTrades-2026-08-21.csv` →
   `agg_trade_id,price,quantity,first_trade_id,last_trade_id,transact_time,is_buyer_maker`
   `[MEDIDO 2026-09-02]`).
5. **Taxa ≤ `max(1 Hz, 1/TF)`** — `assertBucketSpacingWithinInterval` recusa espaçamento entre
   buckets consecutivos mais fino que o intervalo pedido (a assinatura de um tick disfarçado
   de bucket extra).

Deliberadamente agnóstico do schema completo de içamento de `D3` (sessão/painel/célula):
nenhuma ADR fixa essa forma para a resposta histórica ainda, e esse payload é escopo de
`charts` (item 5.4), fora deste componente. Os portões 4 e 5 protegem qualquer payload que uma
rota futura sirva, sem assumir um schema que ninguém decidiu.

**Falsificadores, não só "os testes passam":** cada portão tem teste de MUTAÇÃO — um payload
limpo que passa é alterado plantando o defeito exato que a ADR proíbe, e o mesmo teste prova
que a alteração agora reprova (`is_buyer_maker` plantado ⇒ `assertNoTickLevelFields` lança;
ponto a 500ms do vizinho plantado ⇒ `assertBucketSpacingWithinInterval` lança; `barPolicy`
removido da URL ⇒ `decodeHistoryRequest` lança nomeando `ADR-005/D4`).
