## Mutações — os 5 eixos do briefing, cada um reintroduzido e revertido

1. **`op` com default silencioso** (`requireOperatorParam`: `params.get("op") ?? ">"`) — PEGO.
   `decode REFUSES a bundle missing op, on every variant` falha com
   `AssertionError: Missing expected exception`. Revertido, confirmado no diff.

2. **`min_obs` ausente aceito em Percentile** — duas variantes testadas:
   - default `0` (inválido) — PEGO por `assertPositiveInteger` (mensagem "must be a positive
     integer", não "is missing" — pega, mas por checagem de VALOR, não de PRESENÇA).
   - default `1` (válido, para isolar se a checagem de PRESENÇA em si existe) — PEGO:
     `decode REFUSES a Percentile bundle missing minObs` falha com
     `AssertionError: Missing expected exception`, confirmando que o teste cobre ausência,
     não só valor fora do domínio. Revertido.

3. **Decode sem `ThresholdSpec` na URL não recusa** (`decodeThresholdSpec`:
   `params.get("variant") ?? "absolute"`) — PEGO, 2 testes falham: `D8.3: decodeThresholdSpec
   on an EMPTY URL refuses…` e `D8.3: a URL missing only the discriminator still refuses…`. O
   teste negativo obrigatório de D8.3 funciona. Revertido.

4. **`Custom{expr}` decodificável apesar de desabilitado** (`variant === "custom"` devolvendo um
   `AbsoluteSpec{pct:0,op:">"}` em vez de lançar) — PEGO: `decode REFUSES variant=custom
   explicitly…` falha com `AssertionError: Missing expected exception`. Revertido.

5. **`spec_version`** — dois sub-eixos:
   - **ausente aceito** (`decodeBundle`: `params.has("specVersion") ? … :
     CURRENT_THRESHOLD_SPEC_VERSION`) — PEGO, 2 testes falham (`decode REFUSES an unsupported
     specVersion…` deixa de aplicar e `decode REFUSES a bundle missing specVersion…` falha com
     `Missing expected exception`). Revertido.
   - **não participa do hash/identidade** (`bundleHash`: `params.delete("specVersion")` antes de
     hashear) — **ESCAPOU na primeira rodada — 96/96 pass, nenhum teste falhou.** Nenhum teste
     existente comparava o hash de dois `specVersion` diferentes sobre o mesmo `spec`. Isto é
     defeito real de cobertura contra `SPEC-001:568` ("bundle versionado e hasheável" —
     `spec_version` faz parte da identidade que o hash tem que capturar).
