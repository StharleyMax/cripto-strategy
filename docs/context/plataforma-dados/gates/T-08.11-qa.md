## Mutação — os 5 defeitos do despacho, reintroduzidos um a um em `live-transport.ts`, confirmados
pegos pelo teste, revertidos (`cp` de backup em `/tmp/.../scratchpad/live-transport.ts.orig`;

neste worktree ao final).

   `assertNoTickLevelFields` DEPOIS do narrowing (defeito que o builder relata ter corrigido).
   Resultado: `npm run test:app` → **68 pass, 1 fail** — `decodeBucketEnvelope REFUSES a nested
   tick-level field (price inside a plain object field)` falhou com `Missing expected exception`.
   A correção do builder É real: sem ela, `{trade:{price:...}}` vaza. **PEGO.**
2. **Taxa excedendo `max(1Hz,1/TF)`** — `LiveEnvelopeRateGuard.observe` virou no-op (não delega
   mais a `assertBucketSpacingWithinInterval`). Resultado: **67 pass, 2 fail** — o teste de
   recusa literal e o teste de mutação do próprio módulo. **PEGO.**
3. **`is_final` implícito** — `decodeBucketEnvelope` passou a aceitar `is_final ?? false` em vez
   de exigir booleano explícito. Resultado: **67 pass, 2 fail** — omissão e `null` deixaram de
   ser recusados (o caso `"false"` string continuou pego por outro guard, como esperado —
   `typeof !== boolean` ainda dispara para string). **PEGO.**
4. **`bar_policy=intrabar` default silencioso** — `decodeLiveStreamOpenRequest` passou a usar
   `barPolicy ?? "intrabar"` em vez de lançar quando ausente. Resultado: **68 pass, 1 fail** —

5. **`seq` — lacuna não detectada** — `LiveSeqGapTracker.observe` passou a sempre devolver
   `gapDetected: false, missedCount: 0` (mantendo a checagem de monotonicidade estrita intacta,
   só a detecção de lacuna quebrada). Resultado: **67 pass, 2 fail** — o teste de detecção
   direta e o teste de mutação do próprio módulo. **PEGO.** (Não testei "infere do relógio" como
   mutação separada porque `LiveSeqGapTracker.observe(seq)` não recebe nem lê nenhum timestamp —
   estruturalmente impossível inferir do relógio; os 28 testes não têm nenhum input de tempo
   nesta classe, confirmado por leitura de código, não só por não achar um caminho de mutação.)
