## Por que não inventar S4 mesmo sob autonomia (`R9`)

`R9` dá autonomia de decisão de UI/UX — não autonomia para criar uma tela que a árvore de tasks já
atribuiu a outra task (`T-08.6`, dependente desta). Gerar `S4` agora seria: (a) decidir layout de
histograma/`distribution`/`scan`/`firing_rate` sem os `Dx` de `charts` que `T-08.6` carrega (`D8.1`,
`D8.6`, `D8.7`, `D8.17`–`D8.20`, todos em `charts`, nenhum em `web`); (b) violar `R5` (nunca redesenhar/
criar tela sem instrução explícita — o handoff pede o oposto: "não pode inventar S4"); (c) produzir uma
tela que `T-08.6` teria de descartar ou reconciliar, gerando exatamente a oscilação de design que este
agente existe para evitar. **Não há decisão de UI real e inevitável aqui** — ao contrário do que o
handoff cogitava como hipótese remota, a leitura de §3.7/§7 não revelou nenhuma.
