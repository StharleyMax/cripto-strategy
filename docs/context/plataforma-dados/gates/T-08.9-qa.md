## Achado — defeito provado (não corrigido; é QA, não builder)

**`assertFrameIsNoticeable` (`frontend/src/charts/s2-asof-frame.ts:133-151`) não recusa
`widthPx: NaN`.** Em JS, `NaN < 4` é `false` — a comparação `frame.widthPx <
AMBIENT_BORDER_WIDTH_PX * AS_OF_FRAME_MIN_MULTIPLIER` (linha 137) nunca dispara para `NaN`
(nem para `undefined`, nem para qualquer string não numérica, ex.: `"abc" < 4` também é
`false` por coerção). Se o `label` contiver o marcador, a função **aceita silenciosamente**
uma moldura cuja largura é inválida — exatamente o caso que "impossível de não notar" deveria
recusar: `width: NaNpx` é CSS inválido, e o motor de renderização tipicamente ignora a
declaração (sem borda visível nenhuma), o oposto do que o falsificador promete provar.

Prova (teste plantado, roda RED contra o código atual — não é opinião):

Este achado responde diretamente ao item 1 do ataque pedido: "tente achar uma largura ... que

detectável a olho), e engana a proteção.
