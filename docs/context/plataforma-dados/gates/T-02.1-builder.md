## O que foi implementado

Seis módulos de produção em `backend/src/modules/sentimento/`:

- `domain/instrument_universe_snapshot.py` — `InstrumentRow`/`InstrumentUniverseSnapshot`,
  `build_instrument_rows` (join `exchangeInfo` ∪ `fundingInfo`, `premiumIndex` como segunda
  testemunha), `market` derivado por membership (`MARKET_USDS_M`/`MARKET_COIN_M`),
  `compare_symbol_sets`, `funding_interval_hours_distribution`, `exchange_info_fingerprint`
  (projeção estreita para `D2.5`) e `InstrumentUniverseSnapshot.fingerprint` (projeção larga
  para `D2.2`). Puro, sem I/O — contrato `Natureza` mantido.
- `use_cases/capture_instrument_universe_snapshot.py` — a confirmação em duas leituras de
  `exchangeInfo` (`SPEC-001` §3.4), com `UnstableExchangeInfoReadError` quando divergem.
- `infra/binance_futures_snapshot_client.py` — cliente `http.client` (padrão de
  `https_quota_probe.py`), conexão nova por chamada, `UnexpectedStatusError` em não-200.
- `infra/instrument_universe_snapshot_store.py` — grava cru + `received_at` em
  `data/snapshots/instrument-universe-<data>.json.gz`; `latest_snapshot_date`/`dated_snapshots`
  tornam `D2.1` trivial de medir depois.
- `infra/daily_instrument_universe_snapshot_cli.py` — raiz de composição: duas leituras de
  `exchangeInfo`, uma de `fundingInfo`/`premiumIndex`, grava, reporta uma linha JSON em
  `stdout` (registrador nomeado, `ADR-008/D2`).
- `infra/instrument_universe_diff_cli.py` — compara dois snapshots arquivados (`D2.2`-`D2.5`
  reproduzíveis depois, sem código novo).

Seis arquivos de teste espelhando os seis módulos (39 testes novos).
