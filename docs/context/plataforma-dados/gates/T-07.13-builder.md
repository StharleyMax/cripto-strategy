### Por que não editei `domain.ts`/`fixtures.ts`/`view-model.ts`/`S1Console.tsx`

`frontend/` não tem aplicação Next.js rodando (`[MEDIDO 2026-09-02: grep -c '"react"'

reusa `buildS1ViewModel` sem alteração — então no dia em que existir onde chamá-la, a troca é
de UMA chamada, não de reescrita.

### Escopo deliberadamente NÃO coberto (registrado, não escondido)

`collectorRowsFromIngestHealthProjection` mapeia `IngestHealthRunRow` → `CollectorRow` de
forma MÍNIMA: `retention` é `unmeasured` (a consulta nunca emite `janela_de_perda` != null em
F0 — `ingest_record.py:91`) e `resilience` é sempre `not_scored` (a consulta não carrega sinal
de SLO-trail). A classificação de fórmula por série (`D7.12`-`D7.14`, `computed_uniform` vs

inventá-los a partir de colunas que não os carregam seria a mesma classe de invenção que o
handoff proíbe para o endpoint HTTP, generalizada. `T-07.12`'s fixtures continuam sendo a
única fonte dessas duas colunas até uma task futura decidir como derivá-las de dado real.
