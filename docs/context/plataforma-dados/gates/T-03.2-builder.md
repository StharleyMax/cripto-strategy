## Desenho

**Reaproveitado de `T-03.1` sem duplicar**, porque é a mesma classe de stream
(`wss://fstream.binance.com`): `ByteChannel`, `WebSocketMessageSource`, `connect_tls`, e a
pilha RFC 6455 completa de `rfc6455_client.py`. Nada disso foi copiado ou reescrito.

**Novo, cinco arquivos:**

- [`domain/force_order_envelope.py`](../../../../backend/src/modules/sentimento/domain/force_order_envelope.py) —
  `ForceOrderEnvelope`, os 5 campos (`received_at`, `stream`, `doc_snapshot_date`,
  `subsampling_semantics_label`, `raw`) em ORDEM DE CONTRATO (`FORCE_ORDER_ENVELOPE_COLUMNS`),
  mesmo raciocínio de `INGEST_HEALTH_RUN_COLUMNS` em `ingest_record.py`. `raw` nunca é
  parseado — só embrulhado.
- [`domain/force_order_capture_outcome.py`](../../../../backend/src/modules/sentimento/domain/force_order_capture_outcome.py) —
  a decisão de desenho central: `ForceOrderConnected` (pode ter `messages_captured == 0`,
  porque `!forceOrder@arr` é mercado inteiro e ESPARSO) separada por TIPO de
  `ForceOrderNotConnected` (falha de handshake, nomeada por `ProbeStage`). Reusa `ProbeStage` e
  `WindowEnd` de `stream_probe_outcome.py` (`T-03.1`) em vez de duplicar os dois enums.
- [`use_cases/capture_force_order_stream.py`](../../../../backend/src/modules/sentimento/use_cases/capture_force_order_stream.py) —
  conta mensagens cruas dentro da janela declarada. **Nunca decodifica um único payload** — o
  "zero normalização" do DoD é estrutural aqui: não existe branch que leia um campo de
  liquidação, porque nenhum JSON é carregado nesta camada.
- [`infra/force_order_raw_recorder.py`](../../../../backend/src/modules/sentimento/infra/force_order_raw_recorder.py) —
  decorator de `MessageSource` que grava cada mensagem crua envelopada. **Abertura de arquivo é
  LAZY** (só no primeiro `raw`): uma janela quieta não fabrica um arquivo de evidência vazio que
  pareceria "gravou zero" em vez de "nada chegou para gravar".
- [`infra/force_order_collector_cli.py`](../../../../backend/src/modules/sentimento/infra/force_order_collector_cli.py) —
  o probe curto. `rc=3` = "não conectou" (nomeando o estágio); `rc=0` = "conectou", **mesmo com
  `n=0`** — a convenção `rc=3`="não mediu" de `aggtrade_nq_probe_cli.py` (`T-03.1`) mapeada para
  "não conectou", nunca para "mercado quieto".
