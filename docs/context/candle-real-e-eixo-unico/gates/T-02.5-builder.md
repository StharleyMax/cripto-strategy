# `T-02.5` — builder — A rota vira `/symbol/[symbol]`, segmento em inglês

`[QA GATE — Fase 02: eixo único]`
**Feature:** `candle-real-e-eixo-unico`  **Componente:** `web`

## O que mudou

- `frontend/src/app/symbol/page.tsx` **movido** para
  `frontend/src/app/symbol/[symbol]/page.tsx` (novo arquivo) — a rota estática vira dinâmica,
  segmento `symbol`, em inglês. Só o arquivo especial do router (`page.tsx`) mudou de diretório;
  `SymbolClient.tsx`, `view-model.ts`, `series-history-client.ts`, `request-window.ts` e
  `panel-status.ts` continuam em `frontend/src/app/symbol/`, sem mudar (os imports do novo
  `page.tsx` só ganharam um `../` a mais).
- O route handler agora recebe `params: Promise<{ symbol: string }>` (Next 16 App Router),
  normaliza para maiúsculas e valida contra `PILOT_SYMBOLS = ["BTCUSDT","ETHUSDT","LINKUSDT","SOLUSDT"]`
  (transcrito de `backend/src/modules/sentimento/domain/availability_probe_set.py::AVAILABILITY_PROBE_SYMBOLS`,
  lido — nunca re-derivado). Segmento fora do conjunto → `notFound()` (`404`), nunca um `200`
  sobre um instrumento nunca catalogado.
- Toda função do route (`resolveCatalogEntry`, `resolveOhlcCatalogEntry`, `fetchPanelRows`,
  `buildLiveUrl`) passou a receber `symbol`/`routeSymbol` como PARÂMETRO — antes fechavam sobre a
  constante `SYMBOL` (`"BTCUSDT"`) importada de `charts/index.ts`. `charts/s2-panels.ts` **não foi
  tocado**: `S2Panels.symbol` continua a constante fixa do `charts` (`ADR-003`, este task é
  `components = ["web"]`), e por isso `SymbolClient` passou a receber `symbol` como prop EXPLÍCITA
  da rota (`SymbolClientProps.symbol`), usada nas duas exibições que antes liam `panels.symbol`
  (o `h1` sr-only e o prop `symbol` de `LongShortPane`).
- 8 specs e2e (`08`–`15`, mais `11-canvas-fundo`) tinham `SYMBOL_PATH = "/symbol"` literal —
  atualizados para `` `/symbol/${SYMBOL}` `` (todos já tinham/ganharam `const SYMBOL = "BTCUSDT"`).
- 5 testes `*-dom-contract.test.ts` (price/cvd fixo, oi/liquidation/long-short) liam `page.tsx`
  por caminho relativo direto — atualizados para `path.join(HERE, "[symbol]", "page.tsx")` — e 3
  deles (`price`, `long-short`, `oi`, `liquidation`) tinham regex ancorado no call-site antigo
  (sem `symbol`/`routeSymbol`) — atualizados para o novo formato de chamada.
