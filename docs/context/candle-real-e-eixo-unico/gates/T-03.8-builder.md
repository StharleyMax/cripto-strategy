# `T-03.8` (`CST-223`) — Testes diferenciais: `STOCK` não soma (senão 12× o OI real) e `FLOW` soma

> Fase `03` · componente `sentimento` · `CA-8` (`PRD-008` §10), `RN-3`, `RF-7`, `plano 03` DoD 2 + DoD 3.
> Branch `task/candle-f03-t03-8`, worktree `candle-f03-t03-8`, base `wave/candle-f03` (já com
> `T-03.1`/`T-03.2`/`T-03.3`/`T-03.4`/`T-03.5`/`T-03.9`/`T-03.10` mergeadas).

## Escopo e o que já existia

`reduce_bucket` (`domain/series_reduction.py`, `T-03.1`) não foi tocado — a instrução do handoff
foi explícita: é o SUT, não o alvo de mudança. `T-03.1` já tinha dois testes falsificadores
genéricos sobre a mesma dupla `(STOCK,POINT)`/`(FLOW,SUM)`
(`test_stock_point_never_sums_the_48x_defect_rn_3_names`,
`test_flow_sum_is_the_total_not_the_last_fact`), mas com `values` de tamanho arbitrário (`n=12`
e `n=3`) — provam a disjunção `last↔Σ`, não a contagem de fatos nativos que `CA-8` nomeia
literalmente.

`PRD-008` §10 mantém `CA-8` como critério de aceite formal e em vigor, mesmo depois de
`SPEC-008` §5.4 ter julgado o texto de `CA-8` **insuficiente sozinho** (`"morde 1 de 20 trocas"`)
e o ter reforçado com `CA-8′` (4 camadas, escopo de `T-03.7`, ainda não mergeada nesta branch).
`T-03.8` não substitui `T-03.7`: implementa `CA-8` **literal**, como `tasks.toml` a cita
(`CA-8`, `RN-3`, `RF-7`, DoD 2 + DoD 3 de `docs/plans/SPEC-008-candle-real-e-eixo-unico/03_timeframe.md`).

## O que este ciclo adicionou

Duas funções em `backend/tests/sentimento/test_series_reduction.py`, na escala de fatos
NATIVOS que uma janela real de `1h` produz para cada série — não um `n` arbitrário:

- `test_ca8_stock_point_1h_from_its_12_native_5min_oi_facts_is_last_never_their_sum` — `n=12`,
  porque `sum_open_interest.native_grid = "5min"`
  (`domain/open_interest_catalog.py:_NATIVE_GRID`) e `60min / 5min = 12`, o número que `CA-8`
  nomeia (`"soma dos 12 de 5min"`). Valores são um drift realista de OI (~15.230 BTC); a
  asserção não é só `!=` — é `sum/last ≈ 12.0` (`rel=0.01`), quantificando o próprio texto de
  `CA-8`.
- `test_ca8_flow_sum_1h_from_its_60_native_1min_volume_facts_is_sum_never_the_last` — `n=60`,
  porque `klines_volume.native_grid = "1min"` e `60min / 1min = 60`, o número de `DoD 3`.

## Falsificador — a mutação que os dois testes rejeitam

`reduce_bucket`'s `REDUCTION_TABLE` foi mutada EM MEMÓRIA (nunca no arquivo — a implementação
não foi alterada), trocando `(STOCK,POINT)` por `_sum` e `(FLOW,SUM)` por `_last`, e os mesmos
`values` dos dois testes novos foram reduzidos sob a tabela mutada:

```
STOCK mutated (sum instead of last): 182753.99 -- test expects 15230.88 -> would FAIL: True
FLOW mutated (last instead of sum): 628.9 -- test expects 28816.2 -> would FAIL: True
```

Os dois testes rejeitam a troca — não é decoração passando por coincidência de fixture.
