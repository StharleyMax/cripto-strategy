### [WARNING] Rastreabilidade do gate independente não é reconstituível a partir do histórico do repositório

`docs/gate-de-design.md` (dono da política deste gate) é explícito: *"Enquanto ele não concordar, a
decisão de design não vale"* e *"aprovação é o veredito do gate"* (§"Ordem de operação", itens 2 e 4).
O commit `a840f14` afirma que `gates/F1-design.md` é *"a crítica real e independente do `ux-ui-mastery`
(rodada pelo workflow, não pelo `ui-designer`)"* — distinta da autocrítica já commitada em
`local-T-01.3-design:docs/context/camada-de-leitura-do-painel/gates/T-01.3-ux-audit.md` (que o próprio
arquivo se declara **não independente**: *"mesma sessão, persona `ui-designer` (...) não uma segunda
sessão independente"*, achando 4 achados severidade 1, nenhum Must-Fix).

**O que não dá para reconstruir, só a partir de `git log`/`git show`:** nenhum commit no histórico
buscado (`git fetch origin` + `git log --all`) mostra o dispatch de uma sessão separada de
`ux-ui-mastery` produzindo o conteúdo de `gates/F1-design.md` antes de `a840f14` — o arquivo aparece
pela primeira vez já dentro do commit de consolidação. A prosa do próprio `gates/F1-design.md`
("Atualização", linhas 156-169) confirma que o texto "existia" antes mas nunca tinha chegado a um
commit, o que é consistente com a alegação, mas não é **verificável de forma independente** por este
revisor além do que o documento afirma sobre si mesmo. Isto não é um achado de regra bloqueante (não
há `harness rules` id para "gate sem trilha de commit") — é um achado de camada 2, citando
`docs/gate-de-design.md` §"Ordem de operação" itens 2/4 e `CLAUDE.md` §Design (*"agente que gera e
aprova o próprio trabalho não tem gate"*). Correção concreta: quando uma sessão de `ux-ui-mastery`
for despachada como `Task`/`Agent` separado por este workflow, commitar o artefato dela **no mesmo
ciclo**, antes de qualquer consolidação de branch subsequente apagar o rastro.
