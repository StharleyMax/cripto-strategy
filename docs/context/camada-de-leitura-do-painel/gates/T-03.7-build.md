## 2. Achado cruzado, corrigido apenas no arquivo novo — registrado, não escondido

`T-02.2` (`CST-126`, fase `02`, `resolve` hoje `2026-09-07T05:26:18Z`) fixou `API_PREFIX` (default
`/api/v1`) como obrigatório em TODA rota do backend — DoD literal: `"curl $API/ingest-health (sem
prefixo) -> 404"`. **Nenhuma task deste `tasks.toml` atualiza o lado `web`** para construir a URL
com esse prefixo: `ingest-health-query.ts` (arquivo pré-existente, fora do escopo desta task) e o
`collector-status-query.ts` que eu estava escrevendo constroem `new URL("/<rota>", baseUrl)` — sem
prefixo.

**Medido diretamente, não hipótese:** subi o backend real (`seed_ephemeral_ingest_store.py` +
`python -m src.main`, `API_PREFIX` não setado ⇒ default):

```
curl .../ingest-health        -> 404
curl .../api/v1/ingest-health  -> 200 (envelope real)
curl .../collector-status       -> 404
curl .../api/v1/collector-status -> 200 (envelope real, uptimePercent:null aceito pelo parser)
```

Sem correção, `make e2e` (API de pé) media exatamente isso: `collector_status_access_log_hits`
incrementava (a requisição saía), mas `ui_state:ok`/`rows:N` nunca apareciam — `S1` ficava preso
em estado de erro mesmo com a API respondendo, porque a resposta real era `404` (`non_2xx`).

**Correção aplicada, só em `collector-status-query.ts` (arquivo desta task):** `resolveApiPrefix()`
lê `process.env.API_PREFIX` (mesma variável, mesmo default `/api/v1` que
`backend/src/main/__init__.py:47,103` já usa) e a URL passa a ser
``new URL(`${resolveApiPrefix()}/collector-status`, baseUrl)``. **`ingest-health-query.ts` NÃO foi
tocado** — está fora do escopo de arquivo declarado desta task (`T-03.7` refs), e carrega a MESMA
lacuna, não introduzida por mim. **Sinalizado aqui para o coordenador/tech-lead**: parece faltar
uma task (fase `02` ou `03`) que atualize `ingest-health-query.ts` (e os parsers futuros de
`series-catalog`/`series-quarantine`, `T-03.2`-`T-03.5`) para o mesmo padrão — sem ela, qualquer
`make e2e`/deploy real com `API_PREFIX` no default vai reproduzir o mesmo sintoma em `/ingest-health`.
